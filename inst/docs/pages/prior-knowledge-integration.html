1  Prior Knowledge Integration

ariadne (R) and ariadnepy (Python) give access to the same resource: a single graph assembled from public biological databases (Gene Ontology, KEGG, UniProt, BugSigDB, ChocoPhlAn, and more), which can be queried and traversed to link one type of biological identifier to another — for example, taxonomic names to functional pathways, or gene families to disease modules.

This page walks through the same short analysis twice, once in R and once in Python, so you can follow along in whichever language you use.

1.1 Installation

  • R
  • Python
remotes::install_github("Minotau-R/ariadne")
pip install ariadnepy

1.2 Building the resource graph

Both packages expose a single entry point that downloads (and locally caches) the resource graph.

  • R
  • Python
library(ariadne)

graph <- ariadne()
summary(graph)
##  IGRAPH c68c211 DN-- 202 545 -- 
##  + attr: name (v/c), BugSigDB (v/c), ChocoPhlAn (v/c), GM (v/c), GO
##  | (v/c), KEGG (v/c), MSigDB (v/c), OTT (v/c), Rhea (v/c), TIGRFAMs
##  | (v/c), UniProt (v/c), WoL (v/c), source (v/c), url (v/c), source
##  | (e/c), url (e/c)
import ariadnepy

graph = ariadnepy.ariadne()
print(graph.summary())
##  IGRAPH UN-- 202 545 -- 
##  + attr: versions (g), id (v), name (v), specific (v), url (v), source (e), url (e)

1.3 Searching for paths

Before linking two resources, it helps to see which routes connect them. searchPath() / search_path() print the first k shortest paths.

  • R
  • Python
searchPath(graph, ko ~ ec, k = 3)
##  Path 1:
##  ko -(KEGG)-> ec
##  
##  Path 2:
##  ko -(ChocoPhlAn)-> uniref90 -(UniProt)-> ec
##  
##  Path 3:
##  ko -(ChocoPhlAn)-> uniref50 -(UniProt)-> ec
ariadnepy.search_path(graph, "ko ~ ec", k=3)
##  Path 1:
##    ko -(KEGG)-> ec
##  
##  Path 2:
##    ko -(KEGG)-> kegg_rxn -(KEGG)-> ec
##  
##  Path 3:
##    ko -(ChocoPhlAn)-> uniref50 -(UniProt)-> ec

1.5 Weaving a linkmap

weavePath() / weave_path() traverse the chosen path and return a two-column table mapping origin identifiers to target identifiers.

  • R
  • Python
ko2ec <- weavePath(graph, ko ~ ec, k = 1)
##  ko -(KEGG)-> ec
##  Warning: names for 3 ec ids not found.

weavePath() / weave_path() also accept a fixed path table (e.g. from drawPath() / draw_path(), see below) instead of the full graph, which skips path search entirely and re-runs just those steps — useful once you’ve settled on a route and want to reuse it with different init IDs.

1.6 Reproducibility: recording the path used

drawPath() / draw_path() return the resource, version, and URL used at every hop of a path — handy for citing the exact data sources behind a result.

  • R
  • Python
drawPath(graph, ko ~ ec, k = 1)
##    from to source version  url
##  1   ko ec   KEGG  latest <NA>
ariadnepy.draw_path(graph, "ko ~ ec", k=1)
##    from  to source version  url
##  0   ko  ec   KEGG  latest  NaN

1.7 Python only: annotating AnnData objects

ariadnepy additionally provides add_modules() / get_modules(), which attach a linkmap as module-membership columns directly onto an AnnData object’s var (features) or obs (samples) metadata — no R equivalent is needed here since AnnData is Python-specific. Any two-column linkmap works, whether it comes from weave_path()/weave_complex() or from elsewhere; the example below builds one by hand from the bundled butyrate-producer dataset, so it runs without any network access.

import anndata as ad
import numpy as np

butyrate = ariadnepy.load_butyrate()

adata = ad.AnnData(
    X=np.zeros((1, len(butyrate))),
    var=butyrate.set_index("taxname"),
)

# A minimal linkmap: taxon -> a butyrate-production module ID.
linkmap = butyrate[["taxname"]].assign(module="M_BUTYRATE")

adata = ariadnepy.add_modules(adata, linkmap, key="index")
adata.var.head()

##  Butyricimonas           C00246  butyrate         1.0
##  Odoribacter             C00246  butyrate         1.0
##  Agathobacter            C00246  butyrate         1.0
##  Anaerobutyricum         C00246  butyrate         1.0
